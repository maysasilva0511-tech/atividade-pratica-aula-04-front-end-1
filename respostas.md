# Respostas das atividades

## Atividade 1
**O index é responsavel pela estrutura e pelo conteudo da pagina. O css responsavel pelo layout e aparencia**

## Atividade 2
**A declaração é o `<!DOCTYPE html>`**

## Atividade 3
** Deve ser utilizada a tag `<title>`**

## Atividade 4
**A tag que representa o titulo é `<h1>` e a tag `<p>` representa um parágrafo**

## Atividade 5
**A tag `<section>` representa uma seção temática**

## Atividade 6
**A tag `<nav>` agrupa os links de navegação e o atributo `href` define o destino do link**

## Atividade 7
**O atributo `id` identifica unicamente uma seção[cite: 1]. O valor do atributo deve ser `href="#sobre"`**

## Atividade 8
**A tag para imagem `<img>` e o atributo `src` define o caminho**

## Atividade 9
**Tags para agrupar imagem e `<figure>`e `<figcaption>` agrupam a imagem e a legenda**

## Atividade 10
**O atributo `href` define o endereço do destino**

## Atividade 11
** O link interno como 'contato.html' ou '#sobre' direicona para outro arquivo do proprio projeto. E já o link externo como o http direviona para endereço fora do projeto.**

## Atividade 12
**A tag `<table>` representa a tabela, `<tr>` representa uma linha, `<th>` representa uma célula de cabeçalho e `<td>` representa uma célula comum**

## Atividade 13
**O valor `mailto:` cria um link de e-mail**

## Atividade 14
**A tag  `<footer>` representa o rodapé**

## Atividade 15
**A tag `<link>` relaciona o documento e o atributo `rel="stylesheet"` informa que o arquivo é uma folha de estilos**

## Atividade 16
**A propriedade `font-family` define a familia da fonte**

## Atividade 17
**A propriedade color define a cor do texto.A propriedade text-align define o alinhamento**

## Atividade 18
**Os seletores são separados por vírgula**

## Atividade 19
**O símbolo para classe no CSS é o ponto (.) e no atributo HTML é o 'class'**

## Atividade 20
**O símbolo # seleciona um elemento pelo ID**

## Atividade 21
**A propriedade width define a largura.O valor auto ajusta automaticamente a altura**

## Atividade 22
**O 'padding' define o espaçamento interno**

## Atividade 23
**O 'margin' define o espaçamento externo. margin : 0 auto é utilizada para centralizar um elemento de bloco horizontal**

## Atividade 24
**O 'float' permite que um elemento flutue e o valor 'left' posiciona o elemento a esquerda**

## Atividade 25
**'widht' define a largura; 'border-collapse' unifica as bordas e 'border' defina a borda**

## Atividade 26
**A propriedade text-decoration controla a decoraçao do texto e o valor 'none' remove o sublinhado**
